🕌 Amar Amol Apps

Amar Amol Apps is a Flutter-based Islamic application designed to help Muslims practice daily Islamic activities, read Hadith, count Tasbih, learn about the Prophets, and track their daily good deeds.

✨ Features
📿 1. Digital Tasbih Counter
Count Tasbih and Dhikr easily.
Set custom targets such as 33, 99, or 100.
Save Tasbih counts automatically.
Track daily and monthly Dhikr.
Reset the counter when needed.
View previous Tasbih history.
📖 2. Hadith Library
Read Hadith in Arabic and Bangla.
Browse Hadith by collection and topic.
Display Hadith references and authenticity grades where available.
Bookmark favorite Hadith.
Share Hadith with others.
Save content for offline reading.
🌙 3. Daily Amol Tracker
Track daily Islamic activities.
Mark completed Amol.
Track daily and monthly progress.
Set personal worship goals.
View completed activities and history.
🤲 4. Dua and Dhikr
Daily Duas and supplications.
Morning and evening Adhkar.
Duas for sleeping, eating, and traveling.
Arabic text with Bangla pronunciation and meaning.
Save favorite Duas.
🕋 5. Prophets' Names and Stories
Learn about the 25 Prophets mentioned by name in the Quran.
Read their stories and biographies.
Explore Quranic references.
Learn important lessons from their lives.
Bookmark favorite stories.
💚 6. 99 Names of Allah
Display the names of Allah in Arabic.
Show Bangla meanings and explanations.
Save favorite names.
Explore the meanings of the names.
🕌 7. Prayer Times
Display daily prayer schedules.
Show Fajr, Dhuhr, Asr, Maghrib, and Isha.
Calculate prayer times according to location and settings.
Provide optional prayer reminders.
🧭 8. Qibla Direction
Find the Qibla direction.
Use the device compass when available.
Provide instructions for compass calibration.
📊 9. Amol Statistics
View daily and monthly progress.
Track Tasbih counts.
Review completed Amol.
Maintain a personal activity history.
📅 10. Islamic Calendar
Display Hijri dates.
Show important Islamic dates.
Highlight Ramadan and Eid dates.
